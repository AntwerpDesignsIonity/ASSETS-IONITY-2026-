## Quick start

1. Open the searchable [asset directory](https://ionity-global.github.io/ASSETS-IONITY-2026-/) and search by filename, path, format or category.
2. Use **Copy raw URL** for code and integrations, or **Download** for a local copy. Raw files resolve from `https://raw.githubusercontent.com/Ionity-Global/ASSETS-IONITY-2026-/main/<path>`.
3. Read [Brand and Licensing](Brand-and-Licensing) before publishing, redistributing or remixing any asset.

## What is in the repository

| Folder | Contents |
|---|---|
| `brand/` | Master logos, marks, product marks, icons, swatches, design tokens, guidelines, clips and music |
| `business-pack/` | Ready-to-use pack: logos, marks, favicon/web, social, team, documents, motion, brand system, terminal, vector, modern formats |
| `derivatives/` | Generated size ladders — PNG, square PNG, AVIF, ICO, favicon, PWA, social scopes, posters, people, animation |
| `assets/` | Legacy web asset tree (images, css, js, favicon, audio, videos, cookies, licences/policy/EULA text) |
| `Ionity GIF/` | Ionity sticker & emoji packs v2.0 — WhatsApp/Telegram 512, Discord 320, emoji 128, web 800, with-card variants, `.wastickers` |
| `ansi/` | ANSI / ASCII terminal art, banners, MOTD and bash / PowerShell / Python players |
| `4k Walls/` | 4K wallpapers and hero backgrounds |
| `data/` | Links registry and miscellaneous structured data |
| `archives/`, `process/`, `scripts/` | Packed archives, process notes, catalogue generator |
| root | Catalogue (`assets.json`, `assets.schema.json`, `CATALOG.html`), site (`index.html`, `app.js`, `styles.css`), SEO (`sitemap.xml`, `robots.txt`, `llms.txt`), licences, `CITATION.cff`, `CHANGELOG.md` |
